# Create Pull Request

This skill automates inspecting current branch changes against the base branch (`main` or `master`), verifying tests, populating the repository's pull request template, and creating the PR using the GitHub CLI (`gh`).

## Workflow

### 1. Inspect GitHub CLI, Repository Context, and Git Branch Diff
- Verify that `gh` CLI is available and authenticated: `gh auth status`.
- Verify git repository context and remote details: `gh repo view --json nameWithOwner,defaultBranchRef`.
- Determine current branch name using `git branch --show-current`.
- Inspect commits on the branch relative to the base branch: `git log main..HEAD --oneline` (or `master` if `main` does not exist).
- Inspect the full diff: `git diff main..HEAD`.
- Check status to ensure working tree is clean and branch is pushed to remote (`git status`).

### 2. Verify Tests Pass
- Before opening a PR, run the project's test suite (e.g., `go test ./...`, `npm test`, `pytest`, etc.) to ensure all changes pass.
- Do not submit a PR with failing tests without notifying the user or resolving failures.

### 3. Check for Pull Request Template
- Check if a PR template exists in the repository:
  - `.github/PULL_REQUEST_TEMPLATE`
  - `.github/PULL_REQUEST_TEMPLATE.md`
  - `.github/pull_request_template.md`
  - `PULL_REQUEST_TEMPLATE.md`
- If found, read its contents using `view_file` to structure the PR body according to the template format.

### 4. Draft PR Title and Body
- **Title**: Concise, imperative title summarizing the primary intent (e.g., `feat(api): add feature flag for recipe groups`).
- **Body**: Fill out each section of the template cleanly based on actual code changes:
  - **Description**: High-level overview followed by bullet points detailing each major change.
  - **Types of Changes**: Check appropriate boxes (`[x]`).
  - **How Has This Been Tested?**: Explain how verification was performed (e.g., unit test command output).
  - **Related Issue(s)**: Reference any relevant issue or leave empty if none.
  - **Attribution**: ALWAYS end the PR description with:
    ```markdown
    ---
    *PR description generated by Antigravity.*
    ```

### 5. Create PR via GitHub CLI (`gh`)
- Save the drafted PR body to a temporary markdown file in scratch space (`<appDataDir>/brain/<conversation-id>/scratch/pr_body.md`) to prevent shell escaping/quoting issues.
- Execute `gh pr create` using `run_command`:
  ```bash
  gh pr create --title "<Title>" --body-file "<Path to pr_body.md>"
  ```

### 6. Return Result to User
- Provide a concise summary of the created pull request.
- Include a markdown link to the pull request URL returned by `gh`.

## PR Description Template Example

```markdown
## Description
This pull request introduces maintenance improvements and reliability updates across HTTP extraction, background cron execution, recipe importing, and feature flags:

- **HTTP Extractor Timeout**: Added a 15-second timeout to `pkg/extractor`'s HTTP client (`httpClient`) to prevent hanging requests when fetching web pages.
- **Cron Panic Recovery & Logging**: Added panic recovery (`rcron.Recover`) to the `robfig/cron` scheduler chain and implemented `cronLogger` to bridge `zerolog` structured logging with cron event logs.
- **Import Queue Recovery & Execution Timeout**: Added `RequeueStaleInProgress` to recover and requeue import queue items stuck in `in_progress` status. Added a 60-second execution context timeout for individual import processing in `ImportRunner`.
- **Groups Feature Flag**: Updated `Recipe.Import` to optionally extract ingredient and step groups based on a `features.groups` flag in API requests (`ImportURLRequest`), defaulting to `false` for background import queue processing.

## Types of Changes
- [x] Bug fix (non-breaking change which fixes an issue)
- [x] New feature (non-breaking change which adds functionality)
- [ ] Breaking change (fix or feature that would cause existing functionality to change)

## How Has This Been Tested?
- Executed `go test ./...` across all packages. All unit tests passed cleanly.

## Related Issue(s)

---
*PR description generated by Antigravity.*
```
